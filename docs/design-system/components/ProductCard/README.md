# ProductCard

A product in a grid: image, name, vendor and origin, converted price, rating.

Provide `name`, `vendor`, `origin`, `minor`, `currency`, optional `baseMinor`/`baseCurrency`, `rating`, `reviews` (verified purchases only), `badge` (a status key), `image` or `art` placeholder.

- 4 across at 1280px, 2 on phones. Image 1:1 at `radius-lg`.
